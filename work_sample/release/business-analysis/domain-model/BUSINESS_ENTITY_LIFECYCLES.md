# Business entity lifecycles

Estado: candidate_reconstruction  
Confianza: media

| Entidad | Ciclo de vida candidato |
|---|---|
| Solicitud | Creada -> validada -> asignada/gestionada -> completada/rechazada/anulada |
| Caso/expediente | Abierto -> en gestion -> pendiente externo/documento -> finalizado -> archivado |
| Documento | Solicitado -> cargado -> validado/OCR -> aprobado/observado -> descargado/archivado |
| DAV/DAM/DEX | Generado/capturado -> revisado -> observado/aprobado -> enviado/confirmado |
| Embarque | Registrado -> coordinado -> en transito -> entregado/finalizado |
| Cotizacion | Solicitada -> calculada -> revisada -> aceptada/rechazada/duplicada |
| Factura/planilla | Generada -> enviada -> recibida/confirmada -> pagada/conciliada |
| Token tercero | Emitido -> usado -> vencido/revocado |
