# Value proposition

Estado: candidate_reconstruction  
Confianza: baja-media

La propuesta de valor inferida es proporcionar control operacional y visibilidad a procesos complejos de comercio exterior, reduciendo dependencia de intercambio manual de correos/documentos y concentrando estados, evidencias, costos y reportes en una plataforma compartida.

## Valor por actor

| Actor | Valor candidato |
|---|---|
| Cliente | Ver estado, descargar documentos, cargar informacion, revisar aprobaciones y consultar reportes |
| Operacion interna | Coordinar expedientes, validar documentos, gestionar excepciones y mantener trazabilidad |
| Backoffice financiero | Generar planillas/facturas, controlar pagos, gastos y conciliaciones |
| Tercero/proveedor | Acceder o aportar documentacion de forma controlada |
| Direccion | Consultar indicadores, dashboards y reportes consolidados |

## Riesgo

Parte del valor esta codificado como conocimiento tacito en pantallas, SQL y excepciones por cliente. Eso debe preservarse con pruebas de caracterizacion antes de refactorizar.
