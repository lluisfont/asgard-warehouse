# Document validation rules

Estado: candidate_reconstruction  
Confianza: media

| Regla candidata | Aplicacion |
|---|---|
| Tipo documental requerido | Cargas, OCR, aprobaciones y descargas |
| Asociacion obligatoria a caso/cliente | Evita perdida de trazabilidad |
| Formato/extension permitida | PDF, Excel, imagenes, ZIP/RAR segun flujo |
| Datos extraidos por OCR deben revisarse | Documentos con captura automatica |
| Estados bloquean acciones | No aprobar/enviar si faltan documentos o validaciones |
| Duplicados deben detectarse | Facturas, guias, chasis, solicitudes o paquetes |
| Observaciones requieren correccion | Documentos rechazados/observados |
