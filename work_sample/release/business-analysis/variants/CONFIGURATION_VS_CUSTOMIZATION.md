# Configuration vs customization

Estado: candidate_reconstruction  
Confianza: baja-media

| Tipo | Candidato |
|---|---|
| Configuracion | Catalogos, parametros, permisos, reportes habilitados, tipos documentales |
| Customizacion | Ramas por cliente, pantallas especificas, OCR particular, reportes a medida |
| Mixto | Reglas DAV/logistica segun cliente, formatos Excel, dashboards |

## Criterio

Convertir customizaciones en configuracion solo despues de validar que la variabilidad es estable y no contractual.
