# Actor catalog

Estado: candidate_reconstruction  
Confianza: media

| Actor | Tipo | Responsabilidad candidata |
|---|---|---|
| Cliente | Externo | Consulta, carga, aprobacion y seguimiento de solicitudes, documentos y reportes |
| Usuario operativo | Interno | Gestiona casos, embarques, documentos, estados, costos y excepciones |
| Administrador | Interno | Mantiene usuarios, permisos, clientes, parametros y catalogos |
| Agente de aduana | Externo/tercero | Participa en expedientes aduaneros, tramite y documentacion |
| Proveedor/coordinador | Externo/tercero | Aporta informacion, contactos o documentos en procesos logisticos/aduaneros |
| Transportista | Externo/tercero | Participa en rutas, viajes, cargas y entregas |
| Backoffice financiero | Interno | Controla facturacion, planillas, pagos, gastos y conciliaciones |
| Ejecutivo/gerencia | Interno/cliente | Consulta dashboards, KPI y reportes consolidados |
| Sistema OCR | Sistema externo/candidato | Extrae datos desde documentos y alimenta validaciones |
| Servicios de notificacion | Sistema externo | Envia correos o notificaciones realtime |
