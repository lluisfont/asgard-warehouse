# Stakeholder needs

Estado: candidate_reconstruction  
Confianza: media

| Stakeholder | Necesidades candidatas |
|---|---|
| Cliente | Saber estado de operaciones, cargar/descargar documentos, aprobar informacion y obtener reportes |
| Operaciones | Reducir retrabajo, ver pendientes, registrar estados, resolver excepciones y coordinar terceros |
| Finanzas | Conectar operacion con costos, planillas, facturas, pagos y conciliaciones |
| Administracion | Controlar usuarios, permisos, parametros y variantes sin romper procesos |
| Terceros | Acceder a informacion/documentos estrictamente necesarios y aportar evidencias |
| Direccion | Medir cumplimiento, volumen, tiempos, backlog, costos y riesgos |
| TI | Reducir deuda tecnica, controlar integraciones, secretos, seguridad y observabilidad |

## Riesgo

Muchas necesidades estan implementadas como comportamiento historico, no como contrato explicito. Deben preservarse mediante pruebas de caracterizacion.
