# Internal/external actors

Estado: candidate_reconstruction  
Confianza: media

## Internos

- Operaciones aduaneras.
- Operaciones logisticas.
- Backoffice financiero/contable.
- Administracion de sistema y soporte.
- Direccion/gerencia.

## Externos

- Clientes importadores/exportadores.
- Agentes de aduana.
- Proveedores/coordinadores.
- Transportistas.
- Contactos de terceros con token.
- Servicios externos: correo, Pusher/realtime, OCR, SFTP/API y Power BI.

## Frontera

La frontera interno/externo no siempre coincide con permisos tecnicos. Algunos terceros pueden operar dentro de pantallas controladas y algunos clientes pueden tener vistas ejecutivas o transaccionales.
