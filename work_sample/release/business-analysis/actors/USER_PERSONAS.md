# User personas

Estado: candidate_reconstruction  
Confianza: baja-media

| Persona | Objetivo | Friccion candidata |
|---|---|---|
| Cliente consultor | Ver estado, descargar reportes/documentos y responder solicitudes | Dependencia de permisos, filtros y formatos historicos |
| Operador de caso | Mantener expediente actualizado y resolver pendientes | Muchas pantallas, validaciones distribuidas y datos incompletos |
| Analista documental | Cargar, validar, comparar y corregir documentos | OCR imperfecto, formatos variables y excepciones manuales |
| Coordinador logistico | Coordinar rutas, cargas, costos y hitos | Datos repartidos entre catalogos, temporales y pantallas |
| Analista financiero | Generar documentos, controlar cobros/gastos y conciliar | Reglas en SQL/PHP y salidas documentales sensibles |
| Administrador | Mantener usuarios, clientes, roles y parametros | Alto riesgo de cambios con impacto transversal |
| Ejecutivo | Consultar KPI y reportes consolidados | Calidad de datos y definiciones metricas no uniformes |
