# Validation rules

Estado: candidate_reconstruction  
Confianza: media

- Campos obligatorios por solicitud, caso, documento, factura y reporte.
- Tipos y rangos para fechas, montos, codigos, identificadores y catalogos.
- Existencia de cliente, proveedor, agente, puerto, carga, mercancia y estado.
- No duplicidad de documentos, facturas, chasis/VIN o solicitudes segun flujo.
- Consistencia entre documentos OCR y datos capturados.
- Permisos antes de modificar o descargar informacion.
- Reglas de negocio por cliente antes de aplicar defaults generales.
