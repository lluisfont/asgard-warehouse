# Document rules

Estado: candidate_reconstruction  
Confianza: media

- Cada documento debe estar vinculado a una entidad de negocio.
- El tipo documental condiciona validacion, OCR, descarga y aprobacion.
- Los documentos observados requieren correccion antes de avanzar.
- La generacion documental debe conservar datos y formato historico.
- El acceso debe respetar cliente, rol, estado y token.
- Los paquetes documentales deben mantener integridad entre archivos relacionados.
- Las descargas deben evitar rutas arbitrarias y documentos de otro cliente.
