# Eligibility rules

Estado: candidate_reconstruction  
Confianza: baja-media

| Elegibilidad | Criterio candidato |
|---|---|
| Acceso a pantalla | Usuario autenticado, permiso/menu y cliente habilitado |
| Crear solicitud | Cliente/proceso habilitado y datos minimos completos |
| Aprobar documento | Rol autorizado, documento valido y estado correcto |
| Generar reporte | Permiso, cliente, rango/filtros validos |
| Usar token tercero | Token vigente, alcance correcto y entidad asociada |
| Avanzar estado | Precondiciones documentales/datos satisfechas |
| Generar factura/planilla | Operacion con datos financieros suficientes |
