# Product overview

Estado: candidate_reconstruction  
Confianza: media

Asgard Clientes es una aplicacion web legacy para operaciones de comercio exterior, aduanas, logistica, documentos, facturacion/reporteria y acceso de clientes o terceros. El sistema combina pantallas transaccionales, reportes, cargas/descargas documentales, reglas por cliente y procesos de integracion.

## Capacidades visibles

- Solicitudes y gestion aduanera.
- Seguimiento logistico y costos.
- Control documental y OCR.
- Gestion vehicular/importacion.
- Facturacion, planillas, pagos y aging.
- Reportes operativos, ejecutivos y Power BI.
- Seguridad, sesiones, permisos y tokens de terceros.
