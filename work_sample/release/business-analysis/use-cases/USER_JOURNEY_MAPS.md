# User journey maps

Estado: candidate_reconstruction  
Confianza: media

## Cliente consulta operacion

Login -> seleccion de modulo -> filtros por cliente/caso -> consulta de estado -> descarga de documentos/reporte -> seguimiento de pendientes.

## Operador gestiona expediente

Login -> bandeja/modulo -> apertura de caso -> validacion de datos/documentos -> acciones de estado -> notificaciones -> cierre o escalacion.

## Analista documental

Recepcion/carga -> OCR/captura -> comparacion -> observacion/correccion -> aprobacion -> archivo o envio.

## Finanzas

Seleccion de casos/costos -> generacion de planilla/factura -> confirmacion/recepcion -> pago/aging -> conciliacion/reporte.
