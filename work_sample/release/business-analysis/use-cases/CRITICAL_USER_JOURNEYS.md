# Critical user journeys

Estado: candidate_reconstruction  
Confianza: media

1. Cliente/operador inicia sesion, selecciona cliente/proceso y consulta pendientes.
2. Usuario crea solicitud o caso con datos minimos y adjunta documentos.
3. Operacion revisa datos, completa catalogos, asigna responsables y cambia estado.
4. Documento pasa por OCR o validacion manual; si falla, se observa y corrige.
5. Caso avanza por gestion aduanera/logistica hasta cierre operacional.
6. Costos, planillas o facturas se generan y se concilian.
7. Cliente y direccion consultan reportes, dashboards o exportaciones.

## Journeys de alto riesgo

Acceso/2FA, descarga documental, aprobacion DAV/DAM/DEX, generacion de factura/planilla, importacion Excel, OCR y reportes ejecutivos.
