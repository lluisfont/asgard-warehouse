# Use case catalog

Estado: candidate_reconstruction  
Confianza: media

El catalogo contiene casos de uso candidatos por dominio en `business-analysis/use-cases/domains/*/UC-001.md`. Se generaron para los 70 dominios reconstruidos.

## Casos de uso transversales

- Autenticarse y acceder a funcionalidades autorizadas.
- Crear o actualizar solicitud/caso.
- Cargar, validar, observar o aprobar documentos.
- Consultar estado de embarque/caso.
- Generar reporte o exportacion.
- Gestionar cotizacion, costo, factura o planilla.
- Administrar catalogos, usuarios, permisos y parametros.
- Permitir acceso limitado a tercero mediante token.
