# Product boundaries

Estado: candidate_reconstruction  
Confianza: media

## Dentro del producto observado

- Pantallas web PHP para clientes, operadores y administracion.
- Gestion de casos, solicitudes, documentos, estados y reportes.
- Reglas de cliente, permisos, catalogos y parametros en base de datos.
- Generacion y descarga de documentos/reportes.
- Integraciones con correo, notificaciones realtime, OCR/SFTP/API y Power BI.
- Procesos batch o programados candidatos.

## Fuera o no confirmado

- ERP/contabilidad externa como sistema maestro final.
- Servicios OCR de terceros como implementacion interna.
- Scheduler productivo real.
- Contratos formales de APIs externas.
- Reglas regulatorias canonicas no derivables solo desde codigo.
- Validacion humana de procesos y excepciones.

## Criterio

El limite de producto debe fijarse por responsabilidad operativa y por ownership de datos, no solo por carpeta de codigo.
