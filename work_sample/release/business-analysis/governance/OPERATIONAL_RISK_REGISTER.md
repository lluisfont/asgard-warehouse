# Operational risk register

Estado: candidate_reconstruction  
Confianza: media

| Riesgo operacional | Impacto |
|---|---|
| Carga documental fallida | Bloqueo de expediente |
| OCR incorrecto | Datos erroneos o retrabajo |
| Integracion externa caida | Notificaciones/documentos/reportes incompletos |
| Reporte lento o inconsistente | Decision operacional incorrecta |
| Catalogo mal configurado | Fallos de validacion o calculo |
| Estado incorrecto | Caso bloqueado o cerrado indebidamente |
| Permiso incorrecto | Exposicion de datos o bloqueo de usuario |
| Batch no ejecutado | Pendientes, vencimientos o conciliaciones no procesadas |
