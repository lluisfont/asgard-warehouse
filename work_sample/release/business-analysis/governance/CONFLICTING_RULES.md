# Conflicting rules

Estado: candidate_reconstruction  
Confianza: baja-media

Conflictos candidatos a revisar:

- Validacion JavaScript distinta de validacion PHP/SQL.
- Reportes con filtros o formulas divergentes para el mismo indicador.
- Estados documentales parecidos con significados diferentes por dominio.
- Variantes de cliente que contradicen regla general.
- Permisos de menu que no cubren endpoint AJAX o descarga directa.
- Datos maestros duplicados entre catalogos historicos.

## Accion

Resolver con evidencia de uso, owner funcional y pruebas de caracterizacion.
