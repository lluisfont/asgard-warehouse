# Stakeholder map

Estado: candidate_reconstruction  
Confianza: media

| Stakeholder | Interes principal | Evidencia |
|---|---|---|
| Clientes | Seguimiento, documentos, reportes, aprobaciones y trazabilidad | Reportes cliente, DAV, logistica, acceso web |
| Operadores internos | Ejecutar procesos, resolver excepciones y mantener casos | Pantallas de aduanas/logistica/exportaciones |
| Administradores | Gestion de usuarios, permisos, catalogos y configuraciones | Modulos de identidad/master data |
| Finanzas/backoffice | Facturacion, planillas, pagos, aging y gastos | Dominios billing/accounting |
| Agentes/proveedores | Participacion documental o de coordinacion | Contactos, proveedores, tokens, agentes aduana |
| Direccion/gerencia | KPI, Power BI, dashboards y control operativo | Dashboard generico, portal ejecutivo |
| TI/soporte | Continuidad, seguridad, integraciones y mantenibilidad | Arquitectura legacy, secretos, cron, dependencias |
