# Escalation processes

Estado: candidate_reconstruction  
Confianza: baja

No se ha confirmado un flujo formal de escalacion. Se infiere que las excepciones relevantes se elevan a operaciones, administracion, finanzas, TI o cliente segun el tipo de bloqueo.

| Bloqueo | Escalacion candidata |
|---|---|
| Documento observado | Analista documental / cliente / tercero |
| Error de permiso | Administracion funcional / TI |
| Integracion caida | Soporte TI |
| Discrepancia financiera | Backoffice financiero |
| Dato maestro incorrecto | Administrador funcional |
| Plazo o KPI incumplido | Responsable operativo / gerencia |
